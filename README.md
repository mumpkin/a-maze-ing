# A-MAZE-ING

## Description

Our `A-MAZE-ING` is a fancy and ergonomic TUI application for generating mazes randomly or from a seed.

There are two types of mazes: `Perfect` and `Imperfect`.

`Perfect` mazes have only one solution, whereas `Imperfect` mazes can have multiple solutions. They also use different algorithms: we implemented [Wilson's Algorithm](https://weblog.jamisbuck.org/2011/1/20/maze-generation-wilson-s-algorithm), 'cause it's funny seeing a worm build a maze, for `Perfect` mazes and the [Recursive Division Algorithm](https://weblog.jamisbuck.org/2011/1/12/maze-generation-recursive-division-algorithm), 'cause it does beautiful result and gave a hardtime to Anthony, for `Imperfect` mazes.

## Instructions

### Run the program

Clone the git repository.
```sh
git clone <url> <directory>
```
Move to the directory and run make command
```sh
cd <directory> && make
```

### Use the program

Our A-MAZE-ING has a Terminal User Interface (TUI), to use it in a good condition you may set your terminal in full-screen mode.

### TUI Screens

#### Title

That is the first screen shown at startup.

Press to:
- `q`: exit program with the exiting code 0.
- `s`: open [Generate](#generate) and generate a maze instantly.
- `v`: open [Generate](#generate) and generate a maze with generation vizualisation.
- `c`: open [Config](#config).
- `o`: open [Color Schemes](#color-schemes). 

----
#### Config

That screen display all config values.

Press to:
- `q`: exit program with the exiting code 0.
- `t`: open [Title](#title) selection menu. 

----
#### Color Schemes

That screen is where you'll select a color scheme.

Press to:
- `j`: select the next color scheme.
- `k`: select the previous color scheme.
- `q`: exit program with the exiting code 0.
- `t`: open [Title](#title) selection menu. 
- `return`: confirm selection.

----
#### Generate

That screen is where you see maze generation.

Press to:
- `r`: regenerate maze.
- `s`: save generated maze.
- `q`: exit program with the exiting code 0.
- `t`: open [Title](#title) selection menu.
