## Description

Our `A-MAZE-ING` is a fancy and ergonomic TUI application for generating mazes randomly or from a seed.

There are two types of mazes: `Perfect` and `Imperfect`.

`Perfect` mazes have only one solution, whereas `Imperfect` mazes can have multiple solutions. They also use different algorithms: we implemented [Wilson's Algorithm](https://weblog.jamisbuck.org/2011/1/20/maze-generation-wilson-s-algorithm) for `Perfect` mazes and the [Recursive Division Algorithm](https://weblog.jamisbuck.org/2011/1/12/maze-generation-recursive-division-algorithm) for `Imperfect` mazes.
